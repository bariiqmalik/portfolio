## 📄 Site Structure

- **`index.html`** — Hero section with introduction, quick bio, CV download, and social profiles.
- **`About.html`** — Detailed personal background, education, and development interests.
- **`Skills.html`** — Interactive technical skill cards covering Frontend, Backend, and Core CS.
- **`Projects.html`** — Project showcase highlighting featured works including `kisan-mandi-connect` and `unigrade-pro`.
- **`Contact.html`** — Contact details and outreach channels.

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bariiqmalik/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   Open `index.html` directly in your browser or run with Live Server in VS Code.
